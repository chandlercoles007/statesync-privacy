Privacy Policy for StateSync

Effective Date: September 23, 2026

1. Overview

StateSync ("the Extension") is a session backup tool designed for use within a closed laboratory environment. It captures the session state of the active browser tab — cookies, localStorage, and sessionStorage — encrypts it locally, and transmits the encrypted data to a private repository controlled by the laboratory administrator.

This policy explains what data is collected, how it is handled, and the rights of the lab members who use it.

2. Data Collection

The Extension collects the following data from the active browser tab only:

  • Cookies — including name, value, domain, path, secure/httpOnly flags, sameSite attribute, expiration date, and partition key. Some cookie values may contain authentication tokens.
  • localStorage — all key-value pairs stored by the active page.
  • sessionStorage — all key-value pairs stored by the active page.
  • URLs — the main page URL and the URLs of embedded frames, used to associate captured data with the correct website.

The Extension does not collect:

  • Browsing history beyond the active tab URL
  • Website content (HTML, images, text)
  • Passwords or form data
  • Keystrokes, screenshots, or user input
  • Personally identifiable information beyond what is contained within cookies

3. Data Encryption

All captured data is encrypted locally in the browser using:

  • AES-256-GCM for the payload
  • RSA-2048 (OAEP) for encrypting the AES key
  • gzip compression before encryption

The RSA private key required for decryption is held offline by the lab administrator and is never stored in the Extension, on any server, or in the destination repository.

4. Data Transmission and Storage

The encrypted payload is transmitted over HTTPS to a private GitHub repository controlled by the lab administrator. The repository is set to private, and access is restricted to the administrator's account via a scoped access token.

No third-party services, cloud providers, or analytics are involved in the transmission or storage of the data.

5. Purpose of Data Collection

The sole purpose of the Extension is to preserve browser sessions for legitimate lab activities, including:

  • Restoring authentication sessions across lab workstations
  • Backing up session state before tests or experiments
  • Debugging and analysing session behaviour in a controlled environment

All lab members are informed of and consent to this data collection as part of their participation in the lab environment.

6. Data Sharing

No data is shared, sold, or disclosed to any third party. The data remains entirely within the closed infrastructure of the laboratory — from the browser, over an encrypted channel, to the lab-administered repository.

7. Security

  • Encryption: AES-256-GCM + RSA-2048 hybrid encryption
  • Key handling: Private key stored offline; only the public key is present in the Extension
  • Transmission: HTTPS (TLS 1.2/1.3) for all network requests
  • Access control: Repository is private; token is scoped to a single repository
  • No local storage: The Extension does not store captured cookies in browser storage

8. User Control

  • Lab members can disable or uninstall the Extension at any time
  • Data stored in the repository can be deleted by the lab administrator
  • Users who wish to opt out should contact the lab administrator
